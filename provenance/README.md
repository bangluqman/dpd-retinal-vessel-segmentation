# Checksums

This folder lists SHA-256 hashes for study artifacts that are not distributed here:

- `checkpoint_manifest.csv` — trained checkpoints and selected epochs
- `prediction_hash_manifest.csv` — prediction maps and thresholded masks
- `observer_mask_hash_manifest.csv` — DRIVE observer masks used in the annotation check

The hashes can be used to verify those files if they are shared separately.
